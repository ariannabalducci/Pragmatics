# Praggymatics

## Initial Setup
- Run: 
```
npm install next react react-dom
npx prisma generate
```

## Troubleshooting

If something unexpectedly stops working, try the following:

- Delete `./.next`, `./node_modules`, and `package-lock.json`
- Run:

```
npm cache clear --force
npm install
npm audit fix
```
